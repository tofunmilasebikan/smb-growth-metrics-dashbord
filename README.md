# SMB Growth Metrics Dashboard

## Project Status
In Progress

## Overview
This project focuses on analyzing and visualizing SMB growth and marketing campaign performance metrics using a public dataset.

## Dataset
Marketing Campaign Performance Dataset (Kaggle)

## Objectives
- Analyze key performance metrics such as impressions, clicks, CTR, and conversions
- Identify trends and patterns across campaigns
- Build a dashboard to communicate insights clearly

## Tools
- SQL
- Python
- Data Visualization (Tableau / Power BI / Matplotlib)

## Notes
This project uses a publicly available dataset and is intended for learning and portfolio development.
